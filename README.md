# vue-less-inhatc_lms
vue와 less를 이용한 인하공업전문대학 이러닝 웹 페이지 커스텀
<br><br><br>

## 주요 사용 명령어

### 패키지 설치
```sh
npm install
```

### 개발용 컴파일
```sh
npm run dev
```

### 2. vue  (`vue@3.5.13`)
- 사용된 프레임 워크 Vue 3
```sh
npm install vue@3.5.13
```

### 3. vite (`vite@6.0.3`)
- 빌드 도구
```sh
npm install vite@6.0.3
```

### 4. fontAweesome (`@fortawesome/fontawesome-free@6.7.1`)
- 아이콘 라이브러리 (Banner.vue에서 사용)
- `<i class="fa-solid fa-chevron-up"></i>`
```sh
npm install @fortawesome/fontawesome-free@6.7.1
```

### 5. less (`less@4.2.1`)

```sh
npm install less@4.2.1
```
